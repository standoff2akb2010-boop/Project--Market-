═══════════════════════════════════════════════════════════════
  МАГАЗИН - Версия для 64-bit Windows
═══════════════════════════════════════════════════════════════

СИСТЕМНЫЕ ТРЕБОВАНИЯ:
- Windows 10 (64-bit) или Windows 11
- 100 MB свободного места на диске
- Интернет-браузер (Chrome, Firefox, Edge и т.д.)

Python НЕ требуется для работы!

═══════════════════════════════════════════════════════════════
  ИНСТРУКЦИЯ ПО ЗАПУСКУ
═══════════════════════════════════════════════════════════════

1. Скопируйте все файлы с флешки на компьютер в любую папку
2. Запустите файл "Магазин.exe"
3. Приложение автоматически откроет браузер по адресу: http://127.0.0.1:5000
4. Если браузер не открылся автоматически, откройте его вручную

═══════════════════════════════════════════════════════════════
  СТРУКТУРА ФАЙЛОВ
═══════════════════════════════════════════════════════════════

Магазин.exe          - главный исполняемый файл
shop.db              - база данных с товарами
static/              - папка для загруженных изображений
  └─ uploads/        - загруженные изображения товаров

ВАЖНО: Все файлы должны находиться в одной папке!

═══════════════════════════════════════════════════════════════
  ВОЗМОЖНОСТИ ПРИЛОЖЕНИЯ
═══════════════════════════════════════════════════════════════

• Каталог товаров с изображениями
• Добавление новых товаров с загрузкой изображений
• Управление категориями товаров
• Корзина покупок
• Интерфейс кассира для быстрого поиска и добавления товаров
• Поиск товаров по названию

═══════════════════════════════════════════════════════════════
  ТЕХНИЧЕСКАЯ ПОДДЕРЖКА
═══════════════════════════════════════════════════════════════

Приложение работает на локальном сервере Flask.
Порт: 5000
Хост: 127.0.0.1 (localhost)

Если приложение не запускается:
1. Проверьте, что все файлы находятся в одной папке
2. Проверьте антивирус - он может блокировать .exe файл
3. Убедитесь, что порт 5000 не занят другим приложением
4. Убедитесь, что у вас 64-bit система (Панель управления > Система)
